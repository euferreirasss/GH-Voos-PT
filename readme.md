## 📌 Sobre o projeto

O **GH Voos PT** é um projeto de desenvolvimento web criado com o objetivo de apresentar uma experiência digital voltada para viagens e turismo entre **Portugal e Brasil**.

O projeto foi desenvolvido como parte do meu processo de aprendizagem e evolução na área de **Front-End e UX/UI**, com foco em criar uma interface simples, moderna, organizada e adaptável a diferentes dispositivos.

---

## ✨ Funcionalidades

- ✈️ Apresentação de destinos
- 🇵🇹 Conteúdos relacionados com Portugal
- 🇧🇷 Conteúdos relacionados com Brasil
- 🔎 Área de pesquisa/consulta
- 📱 Layout responsivo
- 🎨 Interface moderna
- 🧭 Navegação entre diferentes áreas do site
- 🖼️ Utilização de imagens e elementos visuais
- 📐 Adaptação para computador, tablet e telemóvel

## 📱 Responsividade

O projeto foi desenvolvido pensando em diferentes tamanhos de ecrã.

A interface adapta-se para:

- 💻 Desktop
- 📱 Telemóvel
- 📲 Tablet

Foram utilizadas **Media Queries em CSS** para adaptar a estrutura, tamanhos, espaçamentos e organização dos elementos.

---

## 🎨 UX/UI

Durante o desenvolvimento, procurei aplicar princípios de UX/UI para criar uma experiência:

- simples;
- intuitiva;
- visualmente organizada;
- fácil de navegar;
- adaptável a diferentes dispositivos.

A escolha das cores, tipografia, espaçamento e organização dos elementos foi pensada para transmitir uma sensação relacionada com **viagens, turismo e conexão entre Portugal e Brasil**.
